# Lapyn (Staging)

A pre-release build of the Lapyn plugin that connects to `https://staging.lapyn.com/api/flow/v2/mcp`. Signing in needs an invitation.

Claude Code: `claude plugin marketplace add uselapyn/lapyn-plugins#staging`, then `claude plugin install lapyn@lapyn-staging`.
Turn on auto-update for `lapyn-staging` under `/plugin` > Marketplaces to receive new builds.

Codex: `codex plugin marketplace add uselapyn/lapyn-plugins@staging`, then `codex plugin add lapyn@lapyn-staging`.
